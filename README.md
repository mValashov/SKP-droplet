SketchUpDroplet — невелика переносна програма для конвертації 3D-моделей USDZ → SKP.

Перетягніть один або кілька .usdz на її іконку. Вона автоматично запускає SketchUp у прихованому режимі, імпортує моделі й зберігає .skp поруч з оригіналами. Початкові та наявні файли не перезаписуються.

Потрібен установлений і активований SketchUp із підтримкою USDZ. Сам дроплет не потребує встановлення — достатньо одного EXE. Якщо SketchUp не знайдено автоматично, програма запропонує вибрати його вручну.
